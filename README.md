### Behind the projects

My work spans **web application development** and **applied machine learning**: turning everyday workflows into usable software, and making model predictions easier to inspect.

I’m currently building **Pocketful**, a budgeting and expense-sharing application backed by Supabase and deployed on Cloudflare Pages. My machine learning work includes a six-class skin lesion classifier with an interactive Streamlit interface and local SHAP explanations.

### A clearer picture of everyday spending

Pocketful brings **time-based budgeting** and **group expense tracking** into the same workflow. Remaining funds and time inform a daily spending allowance, while shared purchases are consolidated into balances between friends.

| Product area | Functionality |
| :--- | :--- |
| **Budget management** | Category budgets and daily spending allowances based on the remaining period |
| **Shared expenses** | Expense splitting and net balances between participants |
| **Event planning** | Dedicated budgets with defined start and end dates |
| **Access & currencies** | Email magic-link sign-in and support for multiple currencies |

**Infrastructure:** Supabase backend · Cloudflare Pages hosting

**[Launch application ↗](https://pocketful.pages.dev/login)** &nbsp; · &nbsp; **[Project repository →](https://github.com/Qawwai/pocketful)**

### From structured inputs to interpretable predictions

A **multiclass classification** project using patient metadata and symptoms from PAD-UFES-20. The Streamlit interface combines structured input collection, feature preprocessing, class-probability visualization, and **per-prediction SHAP analysis**.

| Technical area | Implementation |
| :--- | :--- |
| **Feature processing** | Categorical and symptom encoding, lesion geometry, and aggregate symptom features |
| **Inference** | Six-class prediction from an exported model artifact |
| **Interpretability** | Class-probability charts and local SHAP waterfall plots |
| **Delivery** | Interactive Python application with included model artifacts and setup documentation |

**Stack:** Python · Streamlit · pandas · scikit-learn · LightGBM · SHAP · Matplotlib

**[Explore implementation →](https://github.com/Qawwai/Skin-Lesion-Diagnosis-Classifier)** &nbsp; · &nbsp; **[Model & evaluation notes →](https://github.com/Qawwai/Skin-Lesion-Diagnosis-Classifier#model-and-results)**

<sub>Fundamentals of Machine Learning (SWE3050) final project. Educational use; not intended for clinical diagnosis.</sub>
